1. Redes e endereçamento

LAN rede local; WAN abrange grandes áreas; Wi-Fi é tecnologia de rede sem fio, não sinônimo de internet. Internet é rede global; intranet é rede/serviços privados internos; extranet permite acesso controlado a externos. Switch conecta dispositivos em rede local; roteador encaminha pacotes entre redes; ponto de acesso oferece Wi-Fi. IP endereça interfaces; DNS traduz nomes em endereços e outros registros; DHCP fornece configuração de rede.

TCP oferece transporte confiável orientado a conexão; UDP é datagrama sem garantia de entrega pelo protocolo.

2. Web, navegação e pesquisa

HTTP é protocolo web; HTTPS usa TLS para proteger comunicação e autenticar servidor por certificados. Cadeado não prova legitimidade comercial do site. URL tem esquema, domínio, caminho e eventualmente parâmetros. Navegador interpreta páginas; mecanismo de busca indexa conteúdo. Aspas pesquisam expressão, site: restringe domínio, sinal de menos exclui termo conforme mecanismo. Cache armazena recursos para acelerar; cookies guardam dados de sessão/preferências; modo privado reduz rastros locais, não anonimiza frente a rede/servidor.

3. Correio eletrônico e conectividade

SMTP é envio de mensagens; IMAP sincroniza caixa no servidor; POP3 é recuperação de mensagens, com comportamento conforme configuração. Cc copia destinatários visíveis; Cco oculta endereços dos demais destinatários. Responder a todos pode expor informação; links e anexos exigem verificação. VPN cria túnel protegido para tráfego configurado, não impede phishing. Firewall controla tráfego segundo regras; proxy intermedeia requisições.

Exemplos resolvidos e aplicações

Exemplo 01 · Diagnóstico

Site abre por endereço IP mas nome falha: possível problema DNS; não prova falta total de internet. Se apenas sistema interno falha fora da agência, pode depender de VPN ou acesso autorizado. Não alterar configuração corporativa sem suporte.

Rede LAN cobre ambiente local; WAN interliga áreas maiores; internet é rede global de redes; intranet é rede ou conjunto de serviços privados de organização; extranet permite acesso controlado a terceiros. IP identifica interface na rede; DNS resolve nomes; roteador encaminha pacotes; TCP oferece transporte confiável e ordenado, UDP não possui as mesmas garantias. HTTP é protocolo de comunicação web; HTTPS usa TLS para proteger comunicação, mas cadeado não prova que o site é legítimo. Navegador interpreta páginas (Chrome, Firefox, Edge); buscador indexa e localiza resultados. Pesquisas com aspas procuram expressão exata; operador site: restringe domínio em buscadores compatíveis. Verifique URL, fonte e data.

Correio eletrônico: Para identifica destinatários principais, Cc envia cópia visível e Cco oculta os destinatários de outros destinatários. SMTP é associado ao envio; IMAP sincroniza mensagens no servidor; POP3 é usado para recuperar mensagens. Anexos podem transportar malware. Responder a todos deve ser decisão consciente, especialmente com dados pessoais.

Exemplo resolvido · Segurança web e e-mail

Um site falso apresenta HTTPS e endereço parecido com banco. O HTTPS protege conexão com aquele domínio, não garante autenticidade da instituição. Não forneça credenciais; acesse o domínio conhecido por canal oficial. Em comunicado a clientes sem relação entre si, Cco pode preservar endereços, mas use ferramenta autorizada e política de privacidade.
