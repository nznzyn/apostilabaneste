1. Hardware e arquitetura básica

Hardware é componente físico. CPU executa instruções (unidade de controle, unidades aritméticas e registradores); RAM guarda temporariamente programas e dados em execução, normalmente volátil; cache acelera acesso a dados frequentes; SSD e HDD armazenam arquivos persistentemente, SSD sem partes mecânicas, HDD com discos magnéticos. Placa-mãe conecta componentes; GPU acelera processamento gráfico e paralelo. Entrada: teclado, mouse, scanner; saída: monitor, impressora; entrada/saída: tela sensível ao toque, interface de rede.

Não confundir memória RAM com armazenamento de arquivos.

2. Software, arquivos e unidades

Sistema operacional gerencia recursos; aplicativos realizam tarefas; drivers permitem comunicação com hardware; firmware é software de baixo nível incorporado ao dispositivo. Arquivo possui nome, extensão e conteúdo; extensão indica formato esperado, mas renomear .exe para .pdf não converte formato. Bit é unidade binária; byte=8 bits. 1 kB decimal=1.000 B, 1 KiB=1.024 B; distinguir Mbps (megabits/s) de MB/s (megabytes/s). Compressão reduz tamanho; ZIP agrupa e pode comprimir, não é criptografia por padrão.

3. Produtividade e cuidados

Editor de texto formata documentos; planilha calcula e analisa dados; apresentação organiza slides; banco de dados armazena registros estruturados. Atualizações corrigem falhas e vulnerabilidades; instalar apenas software autorizado. Lentidão pode decorrer de RAM insuficiente, CPU, armazenamento, rede ou programas em execução; diagnosticar antes de trocar equipamento. Backup não é simplesmente mover arquivo para outra pasta no mesmo disco.

Hardware são componentes físicos: CPU executa instruções; RAM armazena dados temporários de trabalho (volátil); SSD/HDD armazenam arquivos de forma persistente; placa-mãe conecta componentes; periféricos permitem entrada (teclado, scanner) e saída (monitor, impressora). Bit é unidade binária, byte tem 8 bits. Unidades decimais (GB) e binárias (GiB) usam bases diferentes. Software é conjunto de instruções: sistema operacional gerencia recursos; aplicativos executam tarefas; drivers permitem comunicação com dispositivos; firmware integra controle de hardware. Backup não é equivalente a RAM ou cache.

Exemplo resolvido · Memória e armazenamento

Ao desligar computador normalmente, conteúdo de trabalho não salvo na RAM pode ser perdido, enquanto arquivo salvo em SSD permanece. RAM é volátil; SSD é armazenamento não volátil. Mais RAM pode melhorar multitarefa, mas não substitui armazenamento permanente.
